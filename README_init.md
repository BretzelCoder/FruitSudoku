# 🍎 Sudoku Fruits & Légumes 🥕

Un jeu de Sudoku moderne et coloré utilisant des fruits, légumes et autres thèmes amusants !

## 🎮 Fonctionnalités

- 4 thèmes visuels (Fruits & Légumes, Fruits, Légumes, Acteurs & Actrices)
- 3 niveaux de difficulté
- Système d'aide intelligent
- Vérification en temps réel
- Chronomètre et statistiques

## 🚀 Installation
```bash
# Cloner le projet
git clone [votre-repo]
cd sudoku-fruits

# Ouvrir dans un navigateur
open index.html  # Mac
start index.html # Windows
```

## 💻 Développement

Structure du projet :
- `index.html` - Page principale
- `css/styles.css` - Styles
- `js/config.js` - Configuration
- `js/sudoku-generator.js` - Génération de grilles
- `js/game.js` - Logique du jeu
- `js/ui.js` - Interface utilisateur
- `js/main.js` - Point d'entrée
